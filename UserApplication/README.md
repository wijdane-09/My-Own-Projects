# User Search & Filter App 🔍

An interactive and responsive User Search & Filter Application built using HTML, CSS, and JavaScript.

## 🚀 Features
- Live user search
- Filter users by role (Admin / User)
- Highlight matching results
- Display number of matching users
- Responsive design for mobile devices
- Smooth hover effects and clean UI

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (DOM Manipulation)

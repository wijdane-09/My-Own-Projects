About TickTask

TickTask is a simple and user-friendly task management application designed to help users organize their daily work efficiently.

With TickTask, you can create tasks, set priorities, search, filter, sort, edit, and track your progress in one place.

This project was built using HTML, CSS, and JavaScript to practice front-end development and DOM manipulation.
